## Tensor layout convention

`lswa_forward` uses projected dense tensors shaped `[B, S, D]`, with `S = f * h * w`.
This matches the reference `_lswa_forward` input convention in `wan_video_dit.py`.

The standalone function returns only the LSWA attention output `[B, S, D]`.
The reference method returns `(self.o(x), last_k, last_v)`, so the parity test sets
`sa.o = torch.nn.Identity()` before comparison.

## Port vs adaptation

- Kept the reference chunked gather path, spatial offset generation, validity masking,
  softmax normalization, temporal frame loop, and cache-frame inclusion behavior.
- Adapted `self.lswa_temporal_window` to `window_size[0]`.
- Adapted `self.lswa_spatial_window` to `window_size[1:]`.
- Adapted the output to omit the reference output projection and cache return values,
  matching the required standalone API.
- The required API has no `num_heads` argument. The module uses 12 heads when `D` is
  divisible by 12, matching the reference FlashVSR/Wan Tiny LSWA setting used in
  the parity test, and falls back to one head for small unit-test dimensions.

  `SelfAttention`. The implementation documents and uses the FlashVSR/Wan Tiny
