# Task 10 - Loss Modules

## What changed

- Added `flashvsr_b1/losses/output_loss.py` with `L_output` Huber loss (`beta=0.1`).
- Added `flashvsr_b1/losses/lpips_loss.py` with `L_lpips` decode-to-RGB LPIPS loss.
- Added `flashvsr_b1/losses/block_kl_loss.py` with `L_block` KL teacher-to-student attention loss using clamp-before-log.
- Added `flashvsr_b1/losses/attn_out_loss.py` with `L_attn_out` Huber loss (`beta=0.1`).
- Added `tests/test_losses.py` exactly from the Task 10 prompt.

`flashvsr_b1/losses/__init__.py` was left empty.

## Test design

The tests cover:

- `L_output` equals zero on identical tensors.
- `L_output` matches the smooth-L1 quadratic region at diff `0.05`.
- `L_block` is near zero for identical distributions.
- `L_block` is positive for disjoint one-hot distributions.
- `L_block` propagates gradients to the student distribution path.
- `L_attn_out` equals zero on identical tensors.
- `L_lpips` returns a scalar when `lpips` is installed.
